ЭХО — офлайн-режим и безопасное обновление контента

ЧТО ДОБАВЛЕНО
- PWA-манифест и Service Worker.
- Кеширование оболочки приложения отдельной версией.
- Проверка SHA-256 для каждого HTML-файла главы.
- Фоновая загрузка глав небольшими порциями, по две одновременно.
- Продолжение прерванной загрузки: уже сохранённые проверенные файлы не скачиваются повторно.
- Обновления контента собираются в отдельном staging-кеше.
- При обновлении из сети загружаются только новые/изменённые файлы; неизменённые копируются из действующего кеша.
- Новая версия контента включается только при следующем полноценном запуске.
- Резервное сохранение прогресса восстанавливает основную запись, если та повреждена.
- Ошибка загрузки соседней главы больше не должна затирать уже открытую главу.

УСТАНОВКА
1. Останови локальный сервер: в его окне нажми Ctrl+C.
2. Распакуй архив целиком в корень папки echo-reader.
3. Согласись на замену файлов, если Windows спросит.
4. Убедись, что распакованы папки и файлы с исходными путями.
5. Запусти start.bat заново. Обновлённый PowerShell-сервер теперь правильно отдаёт manifest.webmanifest.
6. В Firefox открой http://127.0.0.1:8000/ и нажми Ctrl+F5 один раз, чтобы перечитать обновлённую оболочку.

ПЕРВАЯ ЗАГРУЗКА
1. Открой приложение и пройди заставку до оглавления.
2. Внизу оглавления появится статус подготовки офлайн-доступа.
3. Дождись сообщения «Все 86 глав доступны офлайн».
4. Если закрыть страницу или потерять сеть раньше, загрузка продолжится при следующем запуске или после возвращения сети.

ПРОВЕРКА ОФЛАЙН-РЕЖИМА
После сообщения «Все 86 глав доступны офлайн»:
1. В окне start.bat нажми Ctrl+C, чтобы остановить сервер.
2. В Firefox нажми обычное Ctrl+R (не Ctrl+F5).
3. Пройди заставку, открой несколько глав, включая дальнюю, например 86-ю.
4. Если всё работает, офлайн-кеш готов.
5. Снова запусти start.bat для дальнейшей разработки.

ВАЖНО
- Первая загрузка должна завершиться, пока сервер доступен. До этого офлайн будут доступны только уже загруженные главы.
- Не очищай данные сайта/хранилище браузера во время проверки.
- Ctrl+F5 используй для принудительного обновления оболочки после установки. Для обычной работы и офлайн-проверки используй Ctrl+R.
- Если внизу оглавления появится предупреждение, пришли его текст целиком.
