# Художественное сопровождение: схема 1

Каждая глава может иметь необязательное поле `artwork` в `data/chapters.json`, например `data/artwork/001.json`. Для глав без отдельного файла используется общий нейтральный фронтиспис. После изменения каталога необходимо запустить `node tools/build-content-manifest.mjs`. Текст главы остаётся отдельным.

```json
{
  "schemaVersion": 1,
  "chapter": "chapter-001",
  "cover": {
    "mood": "cool",
    "effects": ["V01", "V04", "V05"],
    "afterReveal": "animate"
  },
  "scenes": [
    {
      "id": "scene-01",
      "after": "p-001-intro",
      "image": "assets/illustrations/001-scene-01.webp",
      "effects": ["V01", "V03"],
      "afterReveal": "still",
      "audio": {"file": "assets/audio/001-scene-01.mp3", "type": "A01"}
    }
  ]
}
```

Это условный пример формата, не указание художнику оформлять именно первую главу так и не существующие медиафайлы. Для индивидуальной обложки добавьте `cover.image`. Допустимые значения `mood`: `cool`, `neutral`, `warm`. Если индивидуального кадра нет, выбирается соответствующий общий фронтиспис. Настроение автор определяет вручную. Для каждой привязки добавляется устойчивый `data-paragraph-id` к нужному абзацу; этот ID не менять при редактуре. ID `cover` зарезервирован. Отсутствующие привязки отклоняются.

- V01: проявление фотографии, V02: появление из темноты, V03: возвращение резкости, V04: дыхание света и цвета, V05: локальное пространственное эхо (маскированное повторение). Движение после проявления только при `afterReveal: "animate"`; для общего фронтисписа это значение включено по умолчанию. V04 и V05 включаются при пяти секундах бездействия в видимой сцене. При прокрутке или касании движение прекращается.
- A01: предметный звук, A02: окружающая среда, A03: искажение восприятия. Типы определяют авторское назначение файла, не синтезируют звук. Файлы должны быть подготовлены отдельно. Автовоспроизведение только после согласия и при разрешении браузера. Отдельный ручной запуск доступен при включённом звуке.
- В портретном формате фотография заполняет экран, в широком — сохраняет кадр с мягким фоном. Не используются перекрёстные растворения разных сгенерированных фотографий.
- На этом этапе три общих фронтисписа включены в список ресурсов оболочки. Полноценное версионирование, предзагрузка и восстановление индивидуальных сцен и звуков относятся к пакету 5.
