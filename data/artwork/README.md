# Художественная разметка ЭХО, схема 1

Разметка необязательна: существующие главы без неё работают как прежде.
В будущем каталог глав сможет ссылаться на файл через поле `artwork`, например
`data/artwork/001.json`. В первом пакете разметка валидируется, но не отображается.
Файлы медиа и разметки должны быть включены в версионированный офлайн-комплект
до публичного включения художественного движка.

Пример (условные имена, не готовые ресурсы):

```json
{
  "schemaVersion": 1,
  "chapter": "chapter-001",
  "cover": {
    "image": "assets/illustrations/001-cover.webp",
    "effects": ["V01", "V04"],
    "afterReveal": "animate"
  },
  "scenes": [
    {
      "id": "scene-01",
      "after": "p-001-intro",
      "image": "assets/illustrations/001-scene-01.webp",
      "effects": ["V02"],
      "audio": {"file": "assets/audio/001-sound-01.mp3", "type": "A01"}
    }
  ]
}
```

Для авторской привязки у абзаца задаётся постоянный `data-paragraph-id`
(например `p-001-intro`). Не меняйте его при редактуре абзаца.
Для старого текста без ID приложение вычисляет детерминированный ID из
содержимого абзаца; он меняется при правке текста, поэтому не подходит
как постоянная авторская привязка. Дубликаты явных ID и отсутствующие
цели сцен отклоняются. Отключение разметки никогда не меняет текст.
