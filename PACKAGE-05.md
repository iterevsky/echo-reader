# ЭХО: пакет 5. Офлайн и обновления

Рабочая локальная сборка v11, основана на пакетах 3–4 и ветке пакета 2. Не опубликована на GitHub. Документ дополняет PACKAGE-03.md и PACKAGE-04.md и имеет приоритет над прежними инструкциями офлайн-режима. Актуальный PROJECT.md на GitHub не заменяем: его копия в локальном архиве историческая.

## Что изменено

- Манифест издания схемы 2: SHA-256 каталога, всех глав, художественных JSON, используемых изображений и аудио. Версия `0234223351dacd3a01e2`: 86 глав, 1 118 470 байт текста, 3 фронтисписа (567 914 байт), суммарно 1 686 384 байта без оболочки и служебных манифестов. В текущем комплекте нет индивидуальных художественных сцен или реальных аудиозаписей.
- Снимок издания закрепляется за сеансом. Файлы текста и медиа читаются по его манифесту, а не по общей активной версии Service Worker. Исправные байты повторно используются из старых кешей, повреждённые не выдаются.
- Автоматическая загрузка всего текста; предзагрузка универсальных фронтисписов и медиа предыдущей, текущей и двух следующих глав. Полная загрузка по кнопке; в пределах сеанса повторяет незавершённые загрузки при появлении сети. Статус учитывает фактически проверенные сохранённые файлы, а не только успешные сетевые запросы. Объём не включает оболочку приложения.
- Отдельная подготовка новой версии текста. Повторная проверка каждого файла перед активацией при следующем запуске; медиа загружаются отдельно по мере чтения или полной загрузке. Старые вкладки сохраняют свой снимок. Web Locks сериализует изменения маркеров, если доступен. Старые кеши намеренно не удаляются до отдельного безопасного решения об очистке; размер кеша может расти.
- Service Worker проверяет полный манифест оболочки перед активацией. Несогласованная публикация блокирует новую установку. Повреждённые файлы оболочки восстанавливаются только при совпадении ожидаемой контрольной суммы; если исправных байтов нет, возвращается ошибка, а не другая версия. Автообновление оболочки не вызывает принудительную перезагрузку открытой главы.
- Медиа загружаются и проверяются перед показом, используются временные blob URL. При удалении сцены URL освобождаются; настройки и прогресс не сбрасываются. При запрете кеширования сохраняется чтение из сети (HTTPS/localhost с Web Crypto).

## Публикация и локальная проверка

После добавления или правки глав, художественных JSON и медиа запустить из корня:

```sh
node tools/build-content-manifest.mjs
node tools/build-shell-manifest.mjs
node tools/check-offline.mjs
```

При изменении файлов оболочки увеличить одинаковый `echo-build` в index.html и `BUILD_ID` в sw.js, затем пересобрать манифест оболочки. Не публиковать неполный комплект и не менять контрольные суммы вручную. Публиковать согласованным Git-коммитом. Для PWA использовать HTTPS либо localhost, а не file://. На Windows сохранён start.bat.
